# Global Cybersecurity Threat Analysis (2015–2024)

A data analysis and visualization project built using **Power BI**, exploring global cybersecurity threats over a 10-year period.

---

## 📊 Project Overview

This project analyzes global cybersecurity threat data from 2015 to 2024, identifying patterns, trends, and insights across different attack types, regions, and industries.

---

## 📁 Files Included

| File | Description |
|------|-------------|
| `POWER BI PROJECT.pbix` | Main Power BI report file |
| `POWER BI PROJECT.pbit` | Power BI template file |
| `Global_Cybersecurity_Threats_2015-2024.csv` | Raw dataset used for analysis |
| `Cybersecurity project PPT.pptx` | Project presentation slides |
| `POWERBI PROJECT IMAGE.png` | Preview image of the dashboard |

---

## 🔍 Key Insights

- Trends in cybersecurity attacks from 2015 to 2024
- Most targeted industries and regions
- Common attack types (malware, phishing, ransomware, etc.)
- Year-over-year growth in cyber incidents
